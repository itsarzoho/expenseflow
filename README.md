# ExpenseCloud - Ultimate PWA

## ✅ All 4 Trackers Combined + Android iOS + Gmail Login

### Features:
- 52 Categories + Custom Add
- 4 Charts: Donut + Pie + Bar + Line (Unique)
- Wallet Balance (Income - Expense)
- Gmail Login (Google OAuth) + Signup + Forgot Password + Email Login
- PWA - Android + iOS Installable - Perfect Mobile Fit
- Vercel 24x7 Live + Play Store Ready
- Full English

### From 4 Trackers:
- Tracker1: Donut, Wallet, Balance, Pie, Salary
- Tracker2: Type Pie, Monthly, Search, Export
- Tracker3: Total Spent, Category, Bar
- Tracker4: Supabase Auth, What Happened

### Deploy:
1. Unzip
2. Upload to GitHub itsarzoho/expenseflow (replace index.html, manifest.json, vercel.json)
3. Vercel auto deploys in 20 sec - 24x7 Live

### Install:
Android: Chrome Menu -> Add to Home Screen
iOS: Safari Share -> Add to Home Screen
Play Store: PWABuilder.com -> Vercel URL -> AAB -> Play Console $25
